# Statistics

This page explains the current learning statistics used in Dit Dit.

## Current tracked signals

- Session-level accuracy for identify mode
- Per-character all-time accuracy
- Rolling per-character accuracy (10, 50, 100 exposures)
- Weak character flags (<80% on rolling-10 with minimum attempts)
- Character confusion pairs (expected vs selected)
- Spaced-review fields per character (ease factor, interval, repetitions, next review)
- Due-review set for Daily Review quick start
- Daily practiced characters (identify mode)
- Current and longest day streaks

## Current adaptive outputs

- Weak Character Practice set
- Daily Review due set
- Dynamic speed recommendation on results (±1 WPM)
