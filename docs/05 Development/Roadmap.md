# Roadmap

This roadmap is the short, active planning view. The detailed historical checklist lives in [[Roadmap and Checklist]].

## Current Implementation

- Touch-first React/Vite app under `app/`
- Browser-based Morse audio
- Local settings and progress persistence
- Structured lesson data
- Missed-character practice
- Key Decode screen with straight-key and paddle input
- Pi appliance deployment under `deploy/pi/`

## Near Term

- Finish repository cleanup and documentation consolidation
- Harden Pi kiosk startup and exit flow
- Improve first-run and practice guidance
- Continue local progress and per-character feedback improvements

## Mid Term

- Expand adaptive-learning rules
- Add stronger statistics and review recommendations
- Improve lesson-path authoring and validation
- Test browser input behavior on target Pi hardware

## Long Term

- Extract a reusable Morse learning core
- Add hardware key, paddle, and GPIO input support
- Support desktop, Pi appliance, and future dedicated hardware surfaces
- Evaluate LICW, Koch, CW Ops, CW Academy, and custom lesson-plan inputs
